An AI-powered English learning Android application published on Google Play.

The app helps users practice English speaking, improve their vocabulary, and learn through story-based speaking scenarios. It also includes voice chat, quiz features, and a dictionary system to support vocabulary learning and revision.

With LLM/OpenAI integration, Wordly AI can create interactive conversations and aims to make the English learning experience more personal and engaging.

In this project, I worked on Android development, voice chat flow, AI integration, quiz/dictionary features, user experience, and the Google Play publishing process.

**Technologies:** Kotlin, Android, OpenAI API, LLM, Voice Chat, Quiz System, Dictionary, AI Integration, Google Play Console
